# Java 25 Features
Java 25 brings several performance improvements and developer experience enhancements.

## Virtual Threads
Virtual threads are lightweight threads that drastically reduce the effort of writing, maintaining, and observing high-throughput concurrent applications. They are managed by the JVM, not the OS.

## Pattern Matching
Pattern matching for `switch` statements allows developers to write cleaner, safer, and more concise conditional logic without repetitive casting.
